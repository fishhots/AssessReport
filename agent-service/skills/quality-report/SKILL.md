name: quality-report
description: 撰写唯一固定的毕业生培养质量评价报告，保留原章节名称并依据本次资料输出。
---

只撰写任务指定的当前章节，title 必须逐字等于任务标题。原模板章节名称与顺序由程序固定；两个新增章节由程序单独生成并追加，模型不得自行新增主章节。学校、毕业届别使用任务参数，不使用样例中的学校或年份。
成文内容按人工报告的主题、统计口径、图表位置组织：本章小结、指标现状、群体/专业差异、培养质量含义依次展开。保留原分析项目，避免把复杂章压缩成少量通用段落。报告标题和学校署名不能沿用原样例的作者/供应商。
人工报告是结构、格式和指标解释的参考；数字、结论和历届变化必须来自本次资料。内容完整性表示主题逐项覆盖，无法支持的主题用具体 gap 交代，不能通过抄写人工报告的事实来补全。

采用正式的高校质量评价语言。先给出本章可支持的发现，再解释培养质量上的含义，必要时提出改进建议。事实使用 finding，基于证据的判断使用 inference，行动建议使用 recommendation，具体证据不足使用 gap。每段事实和判断均标注 source_ids。
按 fixedOutline 保留原二、三级主题，并按 templateTopics 保留人工报告的具体指标标题。内容块填写 subsection，主题路径为“二级 / 三级”，指标路径为“parent / title”（直接使用 templateTopics 值）。复杂章节按实际主题展开，不受固定6–12段限制。一个段落围绕一个发现，给出关键实际结果与含义；样本口径用于内部核对，不要求每段罗列分母。本章小结突出优势、薄弱点及对应行动。核心发现组织为教学成效、培养过程、教师队伍，不把样例中的结论性标题套到本次学校。

正式写法示例：“本校2025届毕业生毕业去向落实率为81.11%。分学院看，外国语学院相对较高，应用技术学院仍有提升空间，学校可加强重点群体的分类帮扶。”示例的数值和比较只有在本次证据一致时才能采用；它只示范文风，不提供校本事实。禁止写“取自本校主要指标表本校平均行；原表未列有效样本数；没有可比届次，故不作趋势判断”。没有对照资料自然只描述当届，不能在正常结果段落尾追加反复免责声明。
不必每项先解释重要性、再复述题意、再说明数据出处。原指标定义确有必要时简短解释一次；正文重点放在结果、差异和教育含义。建议与具体问题相连，不在每个小节重复通用建设口号。topicEvidence 已有结果时优先采用，不把工具覆盖不足当成资料不存在。
评价分项相对高低只支持相对评价与改进重点，不能据此断言建设重心已发生转移、系统已解决资源供给、平台并发能力不足、师生互动未融入课程或某项课程已经重复缺失。此类原因没有过程证据时提出排查建议，不把猜测写成现状事实。正式指标小节通常1–2段、约120–250字；完整细项数据交给图表。

先分析已取得的程序统计，不以问卷设计介绍代替结果。已有可计算字段不得写成缺失。就业流向只能描述分布，不能单独证明产业供需匹配；没有同口径跨届数据不能写“持续提升/同期上行”；未作显著性检验不能宣称统计学显著。建议对应具体发现，避免各章重复泛泛要求加强建设。缺口同类合并，不重复列举几十个缺图编号。
不得因两个题项人数相同就断言来自同一人群。来源未明确境内/境外读研等范围时，保持原题项口径并说明未区分群体，不能先说明范围未知又作确定归属。合计、差值、百分点及新比例必须有程序计算证据；思考分析建议中的自行计算不作为有效来源。

涉及统计数字引用 DATA 或计算证据；参考报告里的统计数字不能直接成为本章的本校指标。能用表格说明分组比较时输出简洁表格，单元格内容与统计口径一致。没有数据时保留章节并指出缺少的具体资料，不输出虚构的分析。

每章的分析要求是内容范围，不是必传文件清单。只依据用户已上传资料，先写有依据的部分；某个指标、比较或子主题无依据时跳过该项结论和对应图表，在 gap 中说明缺少的指标、样本或口径。整章无依据时仍保留原标题与具体缺口，其他章节继续生成，不要求用户上传固定文件名。

选中章节的全部原小节标题必须保留，结论缺口不能导致目录层级或顺序变化。每小节首个事实或判断块的 summary 是20–45字的一句定性结论，不含数字和指标清单；text 写关键数据及教育含义，不重复 summary。只使用本节真实依据作判断，不机械套用人工报告的结论。数字长句不得充当加粗总结。
统计结果 Complete=false 表示示例截取，Count 是完整条数，不表示剩余行不存在。不能把完整一流专业表里的未展示行写成“样本不足”；同名专业须以学院和专业联合核对。境内读研与在本校读研、AI帮助与产教满意、调查自评与直接考核达成须分别解释。没有基准不作“中等/领先/达标”评级，不因其他项目分值较高而推断该项绝对偏低。优先解释程序表，不再自拟重复的摘录表。
参加过研究生考试不是首次落榜或二战的直接证据；没有考试次数、结果和录取状态时仅描述应试经验。毕业生已进入外校研究生阶段的满意度，不足以直接断言本校研究生教学存在问题；可据此排查本科升学准备与专业衔接支持，避免责任主体错置。
validSamples=null 表示没有统一或已知的总样本数，不表示有效样本为零；分组或矩阵优先读取每行的有效回答数。有效样本里正向回答为零时，0%是实际统计结果，不能当成数据缺失。表格行数是学院专业组或评价项目数，不能作为国家级建设点数量；正式认定层次须有明确名单依据。

最高/最低须核对完整同指标 comparisonCards 和并列项。需求均值、毕业掌握均值、百分比达成度分别表述，不能混排。缺失原因未知时不能解释为样本不足。原模板百分比达成度可来自明确定义的毕业生自评算法，不强行要求直接考核；算法未明则保留指标缺口，可另述已确认量表结果，不冒称达成率。
核心发现每段提炼主要判断，选2–3项证据，不复述完整指标。不同题项、不同群体的比例不能串成确定因果或行为链条。正文不写分析边界、出处和取证免责声明，实际人群范围必须保留。
对“月收入超过万元”“全部专业均较高”等概括须逐一核对所指成员，不能用一个专业的表现代表同句其他专业。低于门槛的专业不包含在该概括中，必要时分开表述。

正文图表承担经过整理的比较结果，不能直接搬运“学院—题项—选项—频数”的多页明细。阅读完整统计后选2–3个关键发现解释差异，结合实际教育问题说明含义；不在图表前后再输出同数值摘录表。建议写成自然连贯的段落，与前面的发现相接，不在每个指标后强行附一条通用建议。保留人工版必要的【建议】形式：核心发现的“教学成效 / 适应度”“培养过程 / “AI+”教育”“教师队伍 / 教学投入”，以及第一至第七章的“本章小结”为 recommendationPaths。存在本次证据支持的具体问题时，在这些位置的发现、分析之后用独立 recommendation 段集中提出对象明确、措施具体的改进建议，程序仅在首个建议段标注【建议】。没有必要措施时不强行输出，其他指标的简短建议自然衔接，技术报告不机械增加建议段。仅参考人工版的位置和写法，不照搬原校本事实或建议内容。
