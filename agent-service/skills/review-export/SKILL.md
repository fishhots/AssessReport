正式输出只有一份报告：原模板选定章节 → 第九章个性化报告（三个固定维度）→ 已填写的第十章用户主题。确有未完成项目时，文末集中附一张简短项目说明表。不得单独生成深度诊断文件，不输出资料来源附录和逐段引用编号。
保留人工模板的封面位置、正文页面、原二至四级标题、指标主题及原图表编号；Word 使用原模板提取的样式、直接格式与表格属性。新章节沿用同一标题体系。章节、小节顺序与任务范围均由程序核对。

检查当前标题是否逐字正确，是否只使用本次任务证据，事实与判断是否有有效引用，数字能否在原始或计算证据中找到。表格各行和表头列数一致，数据与引用口径对应。
检查 subsection 是否来自原小节，趋势是否确有可比历届，缺口是否与 verifiedStatistics 矛盾，自拟表题是否错误使用原图表号。已存在的实际毕业状态、研究生类型、社团、教学、AI、产教融合与校园服务统计不能声称“未提供”。原样占位符、重复引用、整段工具说明和重复缺图清单不得进入正文。

修订只解决给出的校验问题，不能为了通过校验把事实改成建议来隐藏无依据数字。内容修订阶段取证工具已经关闭，只使用 repairEvidence 中提供的原始或计算证据，逐项核对 numericRepairHints。没有候选来源的数值必须删除或改为定性描述；证据不能支持原结论时改写为明确的数据缺口。保持待修订段落、表格的数量和顺序，已通过内容由程序保留。

有限修订后仍无有效依据的部分由程序跳过；可以核实的段落、表格与图表继续输出，缺口说明列出待补充资料。不要因单一主题缺少数据阻止其他章节或诊断生成，不为完成全部内容而编造数字或结论。

正文内容不写开发阶段、Skill、提示词、模型工具调用过程等技术说明。不要输出 Markdown 代码围栏、网页、文件路径或自拟的下载地址。来源由 source_ids 单独提供，排版与文件生成由程序完成。

内部可追溯与正式成文分开：source_ids、原始资料、分母、计算口径和校验记录必须保留在内部审计文件，正式Word只呈现必要结果与简短读者注释。检查已统计但漏写的原小节并补齐，不能统一替换成“本次未形成可核验分析”。模型失败与确实缺资料是不同原因，不能把前者写成要求用户补交已有资料。

visuals 中只能引用本次任务已生成并通过 validate_chart 的资源，图表编号须属于当前章节。检查原图表覆盖情况，缺少数据的项目明确记录。图形由程序插入并控制尺寸和分页，原生表格重复表头、保持可编辑，不把表格转换成截图。

导出逐项核对选中原章节的全部小节标题和顺序；空小节保留标题，具体缺口集中列在文末，不逐项粘贴重复占位话术。专题自拟小标题合法，不能据此剔除正文；专题小标题使用原自动编号，不叠加手写序号。用户专题全为 gap 时应报告未完成并保留已完成章节，不能伪装为成功。加粗仅用于每个小节首段的不含数字的简短总结，避免加粗整段数据。
原模板以外的自拟 gap 标题不单独进入正文或目录，避免产生没有正文的“数据缺口说明”小节；具体限制保留在内部记录和文末项目表。

核对标签与值、完整排序和显著性用语；真数字也可能支持错误结论。教师评价、实习实践和数字化综合表以组别为行、指标为列，重复分组表头；详细分母保留内部统计。只加粗表头与本校汇总，普通数据行不沿用样本行加粗。与程序表完全重复的数据摘录不再插入，具有新增价值的行动/课程映射表保留。
导出失败后的继续生成恢复已验证正文，不重新调用模型，不因新写作规则重写已完成内容。新规则用于新生成；冻结缓存仍校验文件完整性、任务范围、原引用数字及资源。
扩展章节中仅因空格或“五年/5年”等写法不同的等价小标题合并展示，全部正文保留。固定模板的小节名称逐字保留。文末缺口清单按实际未写小节和未完成图表生成；同一小节已有正文时，不因个别废弃判断句而将整节列为“未开展”，具体图表或公式缺口仍应标明。
