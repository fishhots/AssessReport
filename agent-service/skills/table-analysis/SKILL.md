---
name: table-analysis
description: 根据明确的列、分组、筛选条件和样本口径计算毕业生调研指标。
---

先调用 list_sources、inspect_table 确认实际字段，不假定编码含义。纯数值统计要求值可直接解析；带百分号、货币单位或问卷编码的列不能直接作为纯数值计算。

计算前明确届别、样本范围、排除项、有效样本数和缺失值。多选题的频数不能当成互斥选项之和；分组口径不同的数据不能直接比较。比例分母须来自明确证据，不用总体样本数代替该问题的有效回答人数。

优先使用 verifiedStatistics 和 analyze_survey_question 的已计算结果。单选频数和百分比保留全部类别，提示概览可能截断，使用read_statistics分页读取完整明细。拆列多选题经完整0/1编码验证后按1=选中、0=未选统计，以完整作答人数作分母；未作答和跳题不当成0。存在明确“分5级/分7级”量表定义时可报告原量表均值；文本重要性与数值需求/掌握混在同一矩阵时，各子题仍分别统计。配对能力分析的需求均值、掌握均值、差值、掌握不低于需求的回答比例来自同一能力两项均有效的配对回答；最后一项不能改名为人工报告未明确算法的综合达成度。纯数值均值由 summarize_table 返回；其他有来源的比例由 calculate_ratio 返回。不能在脑中估算。工具或概览的展示上限不代表字段不存在，使用 inspect_table 的关键词和 offset 查看完整字段。
对口课程统计使用后台匿名关联的实际毕业状态和专业一致性。重要度只采用编码与文字含义一致的记录；满足度仅以认为课程重要且有效回答满足题的记录为分母，各学院、专业和课程分别保留有效记录数。不将全部课程的平均值替代毕业生层面的达成率。

毕业状态是实际去向，不以“目前的打算”的条件作答样本代替全部毕业生。实际读研、意向读研、境外留学分别筛选；题项混合实际和计划时必须用毕业状态限定。满意度按该人群的有效回答合并“很满意/满意”，保留有效人数。学院均值不能简单平均成全校均值；能力评价记录和课程评价记录不等同于毕业生人数。

百分比变化与百分点差异区分，相关性不写成因果关系。缺少历史/基准数据就只呈现当届；两届合并值不能用于趋势。字段存在且能统计时不得写成数据缺失。真正缺口是不存在的题项、不可确认的编码/算法、可比历届、外部基准或正式分类名单。

需要绘图时使用 prepare_chart_data 从实际列整理数据。已经以百分数表示的值不再乘100；缺失值不填零。学院或专业指标表的“本校平均”行不能计为一个学院/专业，专业表的学院列不能直接当作学院聚合结果。校友推荐度和专业推荐度不是同一指标；两届合并数据不能用于单届对比。代码选项必须有实际编码表，混合单位不能放在同一数轴。

comparisonCards 的排名来自完整同指标结果，核对最高、最低、并列及其标签；不能以截取行推断全体排序。相近比例、同名学院专业和需求/掌握系列分别核对。无检验不说“差异显著”，无明确缺失原因不说“样本不足”。
素养增值工具只有在完整0/1作答、“没有任何提升”与正向选项互斥且无全零回答时，计算至少一项明显提升的比例。矛盾回答口径未明确就暂停该比例，未作答不当作没有提升。均值与达成率转换必须有算法，不从人工报告数值倒推。
