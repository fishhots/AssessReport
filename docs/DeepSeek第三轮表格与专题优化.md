# DeepSeek 第三轮：正文表格与专题结构优化

对比对象为用户提供的 deepseek3.docx 与项目中的人工报告。对照了章节结构、正文表格、第五章统计题项和第十章段落组织，并找到与最新报告一致的任务统计缓存，用同批数据验证修改。

## 本轮发现

| 位置 | 人工报告与生成报告的差异 | 原因与处理 |
|---|---|---|
| 表5-5 主要职业分类AI应用频率 | 人工版26行、6列；生成版252行、5列，含表头 | 生成版按“职业—任务—频率选项”逐行展开，251条频率明细直接进入正文。数据已读取，缺的是报告层面的整理。 |
| 表5-1、5-4、5-6、5-7、5-11 | 生成版分别为45、49、34、34、23行；同一学院或职业名称重复出现 | 转成组别为行、评价项目为列的对照表，并加入本校平均。多选题保留全部选项，取消每组只留前三项的截断。 |
| 表5-2 各学科门类各项实习实践活动满意度 | 表题要求活动满意度，原程序却绑定校内外实践条件评价 | 改为读取对应的活动满意度题项。活动较多时按指标分成两个横向面板，保留全部活动。 |
| 表5-10 教材评价 | 原生成表主要呈现合并后的正向评价 | 改为“非常符合、符合、不符合、非常不符合”完整回答分布，分别统计教材实用性与先进性。 |
| 第一章行业、职业分布 | 表1-6有128行，表1-9有149行；人工版正文主要列示领先类别 | 正文保留比例最高的前五项和适量并列项，比例沿用原总体分母；完整类别保留在计算证据。按专业对照的明细表仍保留全部专业。 |
| 第四、第五章补充表 | 部分模型补充表与自动统计表重复 | 删除指标、列结构、数据完全一致的重复表，保留新增分析或措施表。 |
| 第十章 | 十个小节，每节基本只有一段 | 默认集中为约四个主要主题，要求每节通常2–3段连续分析。用户明确给出提纲时优先遵循用户要求。 |
| 建议段落 | 第九、十章等反复出现“【建议】” | 导出器曾自动加标签；已取消，并清理模型文本中已有的段首标签。提示词要求自然行文，避免每段机械地以“建议”开头。 |

以上原报告行数包含表头。第五章以外也检查了正文表格：第六、七章已经采用的比较矩阵继续保留；仅有两三列的课程、专业表不因行数较多就任意删减。

## 表5-5 的新处理

对全部73组职业任务的有效回答频数计算“高频使用比例＝总是或经常使用人数／该任务有效回答人数”，在各职业内部选取高频使用比例相对较高、较低的代表性任务，形成15行正文摘要；并列任务最多列示两项。

251条频率明细、任务有效回答人数及四种回答频数仍保留在计算证据，供智能体分析与内部核对。不同任务各用自己的分母，程序不会平均各任务的百分比。

上传资料使用15种具体职业分类，人工版使用更粗的职业分类，当前没有提供对应关系。因此保持上传资料的真实分类，不自行映射到人工版的五个大类。资料频率编码不能识别、频数不能核对时，不强行生成摘要。

## 写作与排版约束

前八章固定章节和小节名称保持原模板要求。个性化报告每个维度默认2–3个主要小节；用户专题默认围绕现状与问题、培养方向与学习成果、课程实践与实施路径、实施保障与评价展开。

提示词与 skill 同时约束篇幅和行文。导出程序另有结构整理：将过多小标题归入主要主题，保留原段落、数值和证据引用，避免模型未遵循要求时仍输出十个一段小节。这一兜底只整理结构，不会凭空扩写内容。

对照表保留浅蓝表头、分组表头和本校平均强调。宽表按指标拆分，不退回原始长表；职业任务摘要给任务内容更多列宽。较短比较表避免尾行单独翻页，长表允许跨页并重复表头。

## 修改位置

- `agent-service/assess_agent/report_statistics.py`：完整选项、校均值、正确题项绑定、职业任务摘要和完整频数证据。
- `agent-service/assess_agent/table_layout.py`：领先类别、比较矩阵、宽表分面、旧频率表转置、重复表识别。
- `agent-service/assess_agent/survey_visuals.py`：教材完整频率分布。

- `agent-service/skills/charts-tables/SKILL.md`、`skills/quality-report/SKILL.md`、`skills/deep-diagnosis/SKILL.md`：对应写作与图表规则。

## 验证与适用范围

同批上传资料重新计算已验证：表5-5由251条频率明细整理为15行正文摘要；表5-1、5-6、5-7、5-11的正文矩阵均为12个组别（本校平均加11个学院），补齐低频及零频选项；表5-2包含全部10项活动并按两组指标展示；表5-10保留完整四类频率。

全量测试247项通过、1项跳过；最终分页调整后，100项相关回归测试全部通过。内部制作了表格排版样稿和专题结构样稿，通过 Word 转成 PDF 后逐页检查。原始报告和历史任务文件保持完整。

本轮没有调用付费大模型，没有重新生成完整报告。统计与布局验证使用已有资料和缓存内容；未来新任务会按更新后的提示词、skill 和工具规则生成。已有旧任务的纯导出重试可以整理专题标题、去除标签和转换部分表格，但不会重新计算为新的职业任务摘要。
