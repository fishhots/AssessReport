## 程序更新

- 解析流式错误事件中的错误码、上游状态及已知错误类型，包括 Google 状态名称、数值错误码、嵌套对象或 JSON 字符串，以及 Claude 在 HTTP 200 中返回的错误事件。
- 分别提示认证、余额/额度、限流、接口参数、输入上限、流式兼容性、超时和平台服务错误。未知流式错误明确提示查看模型平台对应调用详情。
- `model-calls.json` 的失败记录新增安全的 `errorDetails`，保留错误来源、已知上游状态和已知错误分类；不记录密钥、原始请求、学校资料、私有思维链或完整错误文本。
- 仍不自动重发已开始处理的付费请求，不把部分输出当作成功分析缓存。
- 本次仅修改错误处理和调用记录，保留同一任务各次尝试的已完成章节与分析检查点，并逐项备份原文件。等待时间、模型配置和写作规则保持当前设置。

接口错误事件依据 [OpenAI 流式错误说明](https://developers.openai.com/api/docs/guides/rate-limits)、[智增增流式接口说明](https://doc.zhizengzeng.com/doc-3990068)及本项目安装的 SDK 实现核查。余额查询采用平台的[查询余额接口](https://doc.zhizengzeng.com/doc-3979937)。这些资料不能证明旧任务具体是哪一种上游错误；目前只能确认相同分析请求现已成功。
