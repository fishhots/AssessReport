# 人工版、DeepSeek、GLM、千问报告逐章对比与智能体优化

本次以用户提供的最新“寄送版”人工报告为参照，比较三份已生成 Word 的章节、小节、正文、表格、图形及页面效果，并回查对应任务的结构化草稿、统计数据、修订记录与校验记录。四个原始文件保持不变。

## 1. 三个模型哪个生成得更好

如果评价的是这次实际下载到的完整交付文件，综合正文分析、原章节覆盖、第九章和第十章的完成情况，本次排序为 **DeepSeek、千问、GLM**。如果只看原模板细项的正文覆盖，则是 **GLM、千问、DeepSeek**。这两个结论评价的对象不同。

| 版本 | 本次表现较好的地方 | 主要不足 | 本次判断 |
| --- | --- | --- | --- |
| 人工版 | 总结句精炼；结果、专业差异、学校特色和建议之间联系清楚；原小节和图表组织完整 | 包含三份生成任务未选的技术报告；部分历届、外部对照、分类及达成度依据不能仅靠本次上传资料重建 | 结构、文风和教育解释的参照，不能把其所有数字当成本次 DATA |
| DeepSeek | 正文解释较充分；能联系实践、专业匹配、就业和AI培养问题；第九、十章有实质内容 | 第一章遗漏最多；总结句堆数字；有读研人群范围和推理边界问题；建议偏长 | 当前交付文件综合可用性最好，但结构完整性不是最好 |
| GLM | 原模板细项覆盖最多；第一章和升学分析组织较全面；个性化分析有校本针对性 | 正文较长，审计口径文字偏多；误把统计示例视为完整专业名单；第十章在导出文件中没有正文 | 原章节覆盖最好；专题缺失主要是程序错误，不能据此断言模型不会写 |
| 千问 | 正文通常较简洁；升学人群区分相对清楚；第十章能够形成培养路径建议 | 第七章遗漏更明显；自拟表较多；有跨指标混用、无基准绝对评级等问题 | 完成交付优于此次 GLM 文件，部分章节分析深度弱于 DeepSeek |

三次任务使用相同的七项材料、原章节选择、六项 Skill 版本和模板版本。分析模式、思考强度、重试次数等并非完全相同，且只有一次任务样本，因此这里是对这三份实际报告的评价，不是对三款模型普遍能力的排名。

GLM 第十章的直接原因已经核实：最后修订草稿含 **7段实质正文，合计2914字**，另有1段缺口说明；其中“现状基础”“现状研判”“情景假设与培养方向”“培养路径建议”“实施条件与评价方式”等自拟小标题，被校验器错误地要求使用原模板固定标题，全部被剔除。导出器也只处理空 subsection，即使放宽校验，原先仍可能丢失带专题小标题的正文。本次同时修复了两处错误，并用原草稿验证7段正文均可通过现有证据和数字校验。

## 3. 逐章内容与格式差异

### 核心发现

三份文件都覆盖了9个细项，但“覆盖了”与“提炼好了”差距明显。人工版先用一句教育质量判断指出学校的表现，再用少量数据展开；生成版常以一串百分比开头，重复后续各章的指标，缺少主次。

人工的“人才培养定位落实较好，毕业生服务首都和进入优质企业的特征突出。”把三个意思收束成一个判断。GLM 对应开头把毕业去向落实率、社会需求符合程度、岗位适应性放在同一句；DeepSeek 另一处开头把教学、母校、生活服务、学生工作、教师指导、岗位适应和就业落实七项指标一起加粗。问题来自成文要求和导出规则共同作用：原来导出器直接将 finding 的首句、最多140字加粗，没有区分总结与数据段。

DeepSeek 能把专业匹配、实践短板和AI培养联系起来，但解释和建议较长。GLM 比较全面，提炼力度不足。千问更短，不过将部分指标称为“中等水平”时没有可核实基准，相对差异被扩大成绝对评级。

本次改为独立 summary 字段：约20–45字的一句定性判断，不含年份、数字、百分比或指标清单；text 写2–3项关键结果及教育含义。每小节只加粗首个事实/判断段的简短总结。旧草稿没有合法短总结时不会继续把数据长句加粗，也不会由程序凭空制造判断。模型误把数字长句填入 summary 时，程序将其移回正文并继续校验数字，不因纯排版问题丢弃有依据的内容。

### 第一章 社会需求适应

人工版按本章小结、毕业去向、未就业分析、区域贡献、领域贡献、雇主特点展开。这一章是三份生成稿结构差异最大的部分。

| 模型 | 主要缺失的原细项 |
| --- | --- |
| DeepSeek | 考研服务期待、求职服务期待；就业地区、就业城市、本市行业、本市职业四项区域贡献；行业一流企业比例及其行业分布 |
| GLM | 本市就业行业、本市就业职业、一流企业所在行业分布 |
| 千问 | 考研服务期待、求职服务期待、就业城市、本市就业行业、本市就业职业、一流企业所在行业分布 |

其中很多字段实际已经上传，不能归为“资料不足”。原来的程序没有为这些图表完成稳定的题项绑定和地域统计，模型取证也不稳定；再加上导出器隐藏空小节，DeepSeek 文件中整个区域贡献主题被省掉。

三个模型的未就业段落也出现从“参加过研究生考试”推断“首次落榜”“二战”的情况。该题直接支持应试经历，不直接支持考试次数或录取结果。人工版只先判断群体已有考试经验、需要备考支持，推理跨度更小。

本次补充准备考研者和仍在找工作者的专门筛选，再统计其服务期待；新增工作所在地、北京市就业行业/职业、自报行业一流企业及其行业分布统计。地区只读取工作单位所在地，不使用生源地；城市缩写不能明确归类的项目保留“尚不能分类”，仍计入分母。一流企业属于自报口径，不当成权威企业认定。

原小节、顺序、编号全部保留，缺口集中列在文末，不再用空项删掉整个主题，也不在每个空小节重复粘贴占位句。图中的问卷填答指引和举例通过确定性简称去掉，原选项仍保存在统计和审计数据中。

### 第二章 就业质量

三个模型均写到17个细项，结构覆盖相对稳定。人工版围绕专业相关度、满意度、收入、岗位适应和离职等指标，挑出主要学院/专业差异，形成培养质量解释。DeepSeek 解释较充分，但反复展开建议；GLM 容易在结果段补样本、分母等审计细节；千问较简洁，部分段落更接近指标表的文字复述。

三份生成稿不足主要是：同一批数据在小结和具体小节反复列出；未经基准支持的“较好、中等、领先”等绝对判断；单届描述无法形成与人工相同的年度趋势；自拟摘录表和已经自动插入的原表重复。

本次强调小结提炼问题与行动，具体小节解释关键差异，完整排序交给原图表；自拟表只保留确有新增对照价值的内容。没有明确的两个可比届次，就只写当届，不把两届合并值拆成两届，更不抄人工版的历史数字。

### 第三章 升学分析

各版境内读研当届比例20.90%等主要指标基本能对齐。人工版还有可比历届、全国基准、“双一流”分类等内容，这些需要相应资料和分类依据，不能仅凭院校名称由模型猜。

DeepSeek 没写院校类型与各学院/专业高水平院校比例；GLM、千问主要缺后者。GLM 和千问较明确区分实际升学与准备升学。DeepSeek 小结将“境内读研满意度90.45%”写成“在校内读研的毕业生中”，又建议排查本校研究生阶段指导，容易把毕业生在外校的体验误归到本校研究生教学。

本次要求境内读研、母校读研、准备考研三个范围分别解释。专业一致题保留原题含义，不因模板叫“相关度”而扩大为跨学科关联性。读研反馈优先用于本科升学准备、专业衔接和生涯支持，不直接断言本校研究生培养存在问题。高水平院校分类缺口保持真实，并保留对应标题。

### 第四章 五育成效

人工版有德育增值、通用能力、工程和商科能力、职业能力、生涯规划、社团等完整组织及学院/学科差异。三个生成版最明显的是篇幅不等于信息完整：DeepSeek 正文较长，但分学院能力达成等关键结果没有补齐；GLM 还缺各项通用能力重要度与达成度；千问较短，并以更多自拟表补充描述。

三个版本共同缺分学科德育增值、各学院通用能力达成、各学院工程毕业要求达成。部分原始能力题测量的是需求/掌握量表均值或满足工作需要的评价记录，不能直接换成综合达成率。人工版里的达成百分比需要实际公式、专业范围与题项定义；不应为了填满模板把原量表随意归一化。

本次继续保留真实的达成口径缺口；可核实的原量表和能力评价记录按原单位解释。统计程序同时修复“全为非正向回答的组被省掉”的问题：有有效回答的0%是实际值，未知样本数用 null，二者都不能冒充资料缺失。

### 第五章 教学培养反馈

三份生成版35个细项全部有正文，是已有工作流覆盖较充分的一章。但人工版把教学满意度、改进需求、产教融合、实习实践、AI教育、教师、课程、教材、专业帮助和双创教育串成培养过程分析；生成版更容易成为逐题描述。

DeepSeek 解释与行动较多，重复和篇幅也较多。GLM 较全面，但结果常夹带长口径说明。千问自拟表较多，出现把产教融合正向评价写成“81.19%至95.71%”的情况；81.19%实际在AI课程帮助项中，不能直接用作另一类项目评价的下界。这说明数字能在引用中找到，还不够证明指标用对了。

本次强化指标名、题项、人群和小节同时对应的要求；每项选择少量关键结果，避免把AI帮助、项目满意度和能力达成互换。课程结果使用有效课程评价记录，不写成毕业生人数。第七章的一流专业课程、教师、实践统计也增加程序覆盖，减少依赖模型临时自算。

### 第六章 满意度评价

三个模型均覆盖20个细项，原主题基本保持。人工版将校友、推荐、就业服务、学生工作、数字化与智慧校园、生活服务分开，并用少量结果说明改进重点。生成版会重复“满意度较高但仍有空间”，或者从某分项较低直接推断资源供给、网络并发或课程互动机制已出现问题。

数据能直接支持相对评价和排查优先级，不能单独证明技术或管理根因。DeepSeek 的解释稍深但易冗长；GLM 统计细节多；千问较简洁，但部分因果和绝对评级仍需约束。

本次要求把没有过程证据的原因写成待验证假设或排查建议；正常结果段不反复写来源、缺趋势和缺样本声明。影响解释的多选、评价记录和实际人群口径仍保留简短注释。

### 第七章 国家级一流本科专业建设点分析

这是三份生成稿与人工版差距最大的综合分析章。人工版有14张原表，覆盖就业质量、能力达成、教学效果和区域产业贡献。DeepSeek、GLM 虽有5/5主题正文，仍有大量“待汇总”式内容；千问仅3/5，缺就业质量、能力达成的实质正文，正文篇幅也最短。

GLM 对表7-8写“8个专业符合条件，其余有效回答不足5人”，但其文件内程序插入的表实际有14个专业结果。原因是给模型的统计证据只展示前6行和后2行，模型把8条示例误认为全部有效行。千问也以少量专业另做摘录表，与完整原表形成重复和不一致。

本次20行以内的小表全部给模型，较大结果明确标记 Complete=false 和完整 Count，不能由示例行推断其余行不存在。程序增加一流专业的就业落实、专业相关、收入、满意度、课程、教师、实践和区域统计。就业指标按学院与专业联合匹配，问卷里同名专业跨学院也分别展示，避免平均不同培养群体。

一流专业范围来自上传资料的明确标注，正式国家级/省级认定层次仍需明确名单。表格行数是学院专业组数，不等于建设点数量。综合能力达成公式尚未提供的内容仍不伪造。仅有单届原始行业/职业数据时，原表号和指标名保持不变，届次标注改为实际当届，不在标题中误写两届合并。

### 第八章 技术报告

人工版包含调查方法、指标与样本说明。三次生成任务没有勾选该章，不作模型好坏判断。本次没有把它强行追加到未选择的任务中。

今后选择该章时，调查总体、回收数、有效样本、问卷逻辑、指标计算口径等按实际资料说明。只拥有回答记录，不能自动推定全校毕业生总体或回收率；教学质量达成公式不因技术报告选中而由模型自行编造。

### 第九章 个性化报告

人工参考稿没有这一章，按已约定的三个问题评价：专业结构与定位、毕业学习成果、课程与实践体系。

三个模型均能生成正文。DeepSeek 最充分，但部分段落接近重抄前几章；GLM 比较集中；千问较简洁，有一些通用方案。共同不足是数据摘录多，建议之间的成果、课程、实践、评价映射还不够清楚。

本次允许维度内的逻辑小标题，保留三个固定维度，要求每项连接校本问题、可观测学习成果、支撑活动、实施条件及验证方式；区分调查自评与直接考核证据。没有课程大纲时不能断言具体课程重复或缺失，但可以提出需要核对的课程映射和评价方案。

### 第十章 用户主题报告

DeepSeek 和千问有实质正文。DeepSeek 有较多校本指标和实施建议；千问更接近阶段性培养路径。GLM 文件只剩未输出说明，但原草稿实际上已经写出上述七段正文。

本次同时修复校验与排版对自拟小标题的处理，去掉与原自动编号叠加的手写序号。未来专题允许基于现状形成情景与建议，不要求事先上传一个已完成的未来方案；缺资料只限制相应事实判断，不应整章退化为 gap。如果最终仍无专题正文，任务明确标为未完成、保存已经完成的章节，不能将空专题算成成功。

## 4. 图表及文档格式对比

四版的主要正文页面尺寸和页边距已对齐，三份生成稿也保留了原模板的蓝色标题、表头及页眉页脚。当前主要差距是段落提炼、局部分页、图形尺寸、标签和重复表格，不是只更换字体就能解决。

在正文超过70字且开头加粗的段落中，加粗片段超过60字的数量为：人工 **1/146**，DeepSeek **88/128**，GLM **54/82**，千问 **91/155**。生成版的长加粗是同一导出规则造成的共性问题。

人工稿的代表性“未就业分析”页可以同时容纳饼图、环形图和两段正文。三份生成稿的同类图采用相同渲染工具，图像含标签的插入宽度常为15.3厘米，大图使后续说明或图题另起一页；长选项还原样带入问卷的填答指引。
