# 图表和表格开发说明

2026-10-04新增全Sheet与字段统计检查、匿名关联的对口课程分析、完整频数与配对能力统计，以及人工版蓝色系绘图。最新真实资料复算、范围与生效方式见[上传资料分析与绘图优化](上传资料分析与绘图优化.md)。

本轮将图表数据整理、绘制、校验和 Word 插入接入现有 LangChain/LangGraph 工作流。固定报告的章节名称、图表编号和标题保留原文。深度诊断继续输出三个维度，可引用图表计算证据。

## 样例清单与实现范围

`agent-service/config/visuals.json` 登记 114 幅图和40张表，包括所属章节、原标题、图形类型、样例 PDF 页码、样本口径要求与可用自动绑定。[模板图表清单](模板图表清单.md)列出了全部项目。

| 类型 | 当前能力 |
|---|---|
| 饼图、环形图 | 互斥比例，合计100%；单指标环形图由程序补充其余比例 |
| 趋势折线图 | 读取实际届次列，至少两个真实数值；缺失年度断线，图下附数值表 |
| 柱形图、条形图 | 单指标或多指标比较；长标签换行、长列表均衡拆图；原表本校平均作基准 |
| 堆积条形图 | 同分母互斥构成，每行合计100% |
| 双向条形图 | 两个同单位正值指标左右对照，坐标显示绝对值 |
| 散点图 | 成对指标，缺少任一项的点不绘制；虚线为有效点的均值 |
| Word表格 | 读取实际字段与原值，保持可编辑；重复表头、单元格边距、数字右对齐 |

支持图形类型与数据读取能力，不等于154项已经全部建立问卷指标的自动计算规则。首版的14幅聚合绑定为：图1-3、1-4，图2-3、2-4、2-7、2-8、2-12、2-13、2-16、2-17、2-20、2-21，图6-2、6-4。学院聚合与专业聚合使用对应工作表，校友推荐度不替代专业推荐度。两届合并表只适用于原清单明确要求合并口径的项目。

2026-10-03更新：在上述14项聚合绑定之外，增加问卷单选、多选拆列0/1、评价矩阵，以及学院/专业升学、实际读研满意度等分组的自动计算和原编号绑定。每题按有效回答统计，问卷跳题不作为否定回答；数值代码只有明确量表定义时才可解释。原本的趋势项目若仅有当届数据，自动展示当届柱图，明确不构成趋势；缺少外部分类、历届或算法仍保留缺口。154项的原二至四级指标位置已登记，图表随对应小节插入，纯缺失的续图不输出。

多维加权指标、毕业要求达成率、德育综合增值率、核心课程综合评价等仍需明确计算定义；量表均值不得替代达成度百分比。该轮实际样本验证及限制见[报告对比与优化记录](报告对比与优化记录.md)。

## Skill与工具

现有6个业务Skill中更新了统计、写作、图表与审校规则，增加 `analyze_survey_question` 后共有10个业务工具；固定文本的连接测试工具另计。

| 工具 | 作用 |
|---|---|
| `prepare_chart_data(spec)` | 从当前任务DATA表读取或统计实际数值，生成带字段绑定、口径与原始证据链的datasetId |
| `render_chart(dataset_id)` | 用Matplotlib绘制原类型图形，或登记原生Word表格资源，返回assetId |
| `validate_chart(asset_id)` | 校验编号、章节、任务来源、数据与计算证据的一致性、比例与图片哈希 |

`spec`需要原图表编号、资料ID、工作表、标签列、指标列、单位和口径。`values`读取已聚合指标；`frequency`以有效回答人数计算选项比例，支持单列分隔多选；`mean`只计算明确量纲的数值；`table`读取可编辑表格。可增加等值筛选、届次列、所属分组列及实际编码表字段。工具不接受任意数值数组、脚本或文件路径。

例如学院专业相关度图：

```json
{
  "template_id": "figure-2-3",
  "material_id": "本次上传资料的UUID",
  "sheet": "各学院主要指标表（最新届次）",
  "label_column": "学院名称",
  "value_columns": ["专业相关度（%）"],
  "mode": "values",
  "unit": "%",
  "basis": "2025届毕业生，学院主要指标表的已聚合数值"
}
```

参数名称采用工具Schema中的下划线形式。含义未知的数值选项须通过实际上传的编码表解码，指定 `codebook_material_id`、`codebook_sheet`、`code_column` 和 `meaning_column`；编码冲突或缺失会拒绝统计。中文字面选项可直接做频数；明确的拆列多选0/1和量表通过预统计或 `analyze_survey_question` 取得合规结果。同名专业可以用 `label_group_column=学院名称` 区分。

## 工作流和输出

1. 解析资料时展开文件中真实的纵向合并文本单元格，不填充普通空白或数值缺失。
2. 遍历本次当届问卷并按题预统计，再加载原图表清单，绑定符合口径的题项统计与同届次聚合表，避免多个来源间随意选择。
3. 将本章图表要求、可用datasetId和缺口交给章节智能体。模型负责选取字段、工具调用和解释结果，数值计算与绘图由程序执行。
4. 把已经确定的图表自动附加到对应章节的小节；模型新增资源也必须校验编号、来源和文件。未勾选章节不输出对应图表。
5. 最终校验后将图形插入Word并附原编号标题、单位、口径和来源；长列表使用同一编号加“续”。表格直接写入Word表格对象。

每次尝试目录增加 `visual-coverage.json`（每项成功或缺口及原因）、`visual-assets.json`（字段绑定、数据、来源链和图片哈希）、`visuals/`（PNG）。计算证据保留在 `corpus.json`，最终 `manifest.json` 增加图表覆盖数量。2.1版正式Word只在文末集中列出未开展项目简表，不输出取证说明和来源附录；完整来源、口径与图表缺项记录保存在内部 `report.audit.json`。整章无依据时仍保留原标题，运行资料保存在当前任务目录。

## 验证和限制

测试覆盖八类图形、可编辑表格、真实合并单元格、同名专业、样本分母、多选重复去重、实际编码表、缺失年度、单位范围、任务隔离、文件和数据修改、LangChain三个新工具循环，以及工作流中的两份Word导出。

2026-10-03复核使用历史 DeepSeek 任务的同一批上传资料：186项题项/指标统计、87/152个选中范围内原图表项目可自动准备并校验。真实 DeepSeek 仅复测第三章，输出11组图表并通过内容校验。没有新增正式任务或覆盖历史输出，未再次完整运行整份付费报告。

已检查中文图形、Word结构、目录更新、正文分页和表格跨页。本机使用 Word 只读导出PDF，再通过文档技能的渲染器逐页检查内部版式文档和第三章复测文档。整份真实成文、剩余复杂指标算法及其覆盖率仍需继续验收；当前排版保留原主题与图表关系，不表示对原PDF每页的精确复刻。具体证据和限制见[报告对比与优化记录](报告对比与优化记录.md)。

部署时需要中文字体。Windows默认读取微软雅黑或宋体，Linux可安装Noto Sans CJK，并用`ASSESS_CHART_FONT`指定字体文件。缺少字体时明确失败；无图形界面的服务器使用Agg后端。

实现依据：[Matplotlib饼图接口](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.pie.html)、[Matplotlib绘图后端](https://matplotlib.org/stable/users/explain/figure/backends.html)、[python-docx文档接口](https://python-docx.readthedocs.io/en/latest/api/document.html)。
