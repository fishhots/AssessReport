## 格式与正式文风

最新报告实际分页155页，人工报告156页，但二者内容范围不同。最新报告的个性化、专题及附录较长，页数相近不代表原模板内容已经完整。原模板封面、页边距、标题色彩与页眉页脚已有较高一致性；明显差距集中在空小节、图注、引用、附录和成文密度。此次检查了最新报告的完整分页图及典型页面，并对新导出另作原生Word排版验证。

最新报告“数据与图表补充说明”约14572字，“资料来源”约13715字，后者有176条来源记录；各正常段落还有引用编号和大量“原表未列、取自某行、不作趋势判断”的说明。这些内容更像系统审计说明，不适合重复放入正式报告。

已改为：

1. 事实、数字、分母、来源ID及计算链仍进行内部验证，并完整保存在章节JSON、统计记录和 `report.audit.json` 中。
2. 正式Word取消逐段引用编号、资料来源附录与图表后的文件出处；正常正文直接写结果、差异与培养质量含义。
3. 只保留会影响读者理解的注释：多选、有效小样本、合并届次、课程/能力评价记录数、工作任务频率等。不再每图粘贴整段工具口径。
4. 不输出固定空项占位语。无结果的小节不制造空标题，原主章节及有内容小节的名称、顺序保持不变；尚未开展的项目在文末一张简表集中列出，不复制模型数千字缺口散文和几十个缺图编号。
5. 图表仍在原主题位置，续图题采用“续图X-X …”，表格可编辑且重复表头；去掉图注后同步调整题注与后文的分页约束。
   专业行业/职业表采用人工报告的学院、专业、主要行业或职业三列布局，每个专业集中展示前三项及比例；不在正式表中重复展开学院名称和有效人数列，详细分母留在内部统计。
6. 正常结果的写法是“本校2025届毕业生毕业去向落实率为81.11%”，无需随后交代工作表行位置、未列样本数或缺少对照资料。没有历届资料就自然描述当届，不捏造趋势。
