# 第1、5、6、7章表格对比与修正

对照文件为人工版《北京信息科技大学2025届毕业生培养质量评价报告.doc》和生成版《北京信息科技大学2025届毕业生培养质量评价报告 (1).docx》。本次逐表检查36张表，只调整表格统计、组织和Word呈现，不修改图形样式或正文写作要求。

人工版这四章有36张表，生成版有33张，表5-2另拆成两个面板，表7-5、7-6、7-7未输出。主要原因包括：统计长表直接进入正文；表头没有逐表约束；合并单元格时拼接了重复文本；人群、指标和满意度分母不一致。以下记录每张表的修正。

| 表号 | 人工版形式及生成版问题 | 修正后的规则 |
| --- | --- | --- |
| 1-1 | 省份名称＋历届；生成版只有当届值 | 按上传资料实际届次动态生成列，当前主要五省份，某届某项缺失时填“—” |
| 1-2 | 城市名称＋历届；生成版把无法分类的地点作为城市 | 城市表头保持人工版样式，届次列按上传资料动态生成；未知地点不作为城市名称展示 |
| 1-3 | 行业类名称＋历届 | 保留主要五类行业，届次列按上传资料动态生成，不把主要类别重新归一化至100% |
| 1-4 | 职业类名称＋历届 | 保留主要五类职业，届次列按上传资料动态生成，原完整分布仍保留 |
| 1-5 | 行业类名称＋历届 | 按实际上传届次形成历届比较，不缩成“类别、当届比例” |
| 1-6 | 行业名称＋历届 | 使用具体行业名称，保留主要五项，届次位置由实际资料决定 |
| 1-7 | 学院名称、专业名称、就业的主要行业；生成版列行业类及多个百分比，合并格重复 | 读取具体行业名称，列人数最多的项目及并列项；学院分组只显示一次；按学院、专业排列 |
| 1-8 | 职业类名称＋历届 | 按实际上传届次生成列并保留两位小数，不丢掉源分母 |
| 1-9 | 职业名称＋历届 | 使用具体职业名称，主要五项保留原比例，届次列动态生成 |
| 1-10 | 学院名称、专业名称、从事的主要职业 | 读取职业名称，不以职业类替代，不在名称中堆百分比；修复合并格重复 |
| 5-1 | 学院名称、教学满意度、教学改进需求；两层表头 | 恢复原学院列名和固定六项需求，保持本校平均及学院对照 |
| 5-2 | 四组“选项、学科满意度”；生成版转置成学科行并拆面板 | 按工学、管理学、理学、文学分别排名六项，保留八列；排除“未参加”分母；课程实验与课程实验（项目）分别计算 |
| 5-3 | 学院名称＋四项校内、四项校外评价；两层表头 | 固定两组表头和八个项目，依项目含义匹配实际字段 |
| 5-4 | 职业分类＋六项AI场景；一层表头 | 读取明示职业一级分类，去掉解释性括号后对应六个表头；额外“其他”留在内部统计 |
| 5-5 | 职业分类、任务及四档频率；生成版细职业分类过多且同类标签未正确合并 | 用明示一级分类整理，每任务保留四档实际比例与内部频数；按高频比例排序；职业合并格只留一次名称 |
| 5-6 | 学院名称＋六项AI能力素养需求；一层表头 | 固定六个指标及原标签，保留零值，不添加原表没有的额外列 |
| 5-7 | 学院名称＋五项AI培养需求；一层表头 | 固定五个项目及原表头，不增加“其他”列 |
| 5-8 | 学院名称、教师指导总体满足度、高频交流、三项指导满足度；两层表头 | 恢复六列及分组；高频交流按每月至少一次及每周至少一次计算；总体指标未给公式时为“—” |
| 5-9 | 学院名称；两类对口人群各有重要度、满足度 | 用匿名键关联问卷与课程记录，四项独立统计；本校平均独立统计，不平均学院比例 |
| 5-10 | 选项、非常符合、符合、不符合、非常不符合；实用性在前 | 恢复完整四档分布及“课程教材实用性、课程教材先进性”的顺序，去掉重复长问题与列名百分号 |
| 5-11 | 学院名称、课程教材实用性、课程教材先进性；一层表头 | 恢复标签、顺序和三列结构，不加多余分组表头 |
| 6-1 | 学院名称＋四项数字化建设效果；生成版混入五项资源内容满意度 | 仅保留一网通办、数字资源、信息技术能力、个性化学习四项，保持一层表头 |
| 7-1 | 专业名称＋历届；生成版另加学院列且无平均 | 学院、专业用于内部联合匹配；正式表只列专业和实际上传届次，加入源文件本校平均原值 |
| 7-2 | 专业名称＋历届工作与专业相关度 | 同上；合并格不再重复学院文本，不平均同名专业 |
| 7-3 | 专业名称＋历届月收入，单位元 | 实际届次、元及两位小数；本校平均采用源指标，已上传届次某项缺失时填“—” |
| 7-4 | 专业名称＋历届就业满意度 | 保留专业和届次结构，届次列动态生成，学校平均与专业值分别取源指标 |
| 7-5 | 专业名称＋历届通用能力达成度；生成版缺表 | 届次列按上传资料生成；明确聚合达成度可直接填入，未定义量表转达成率的规则时保留“—” |
| 7-6 | 专业名称＋历届工程类专业毕业要求达成度；生成版缺表 | 届次列按上传资料生成；须有明确专业范围、计算规则或已聚合指标，不以量表均值替代 |
| 7-7 | 专业名称＋历届工科类核心能力达成度；生成版缺表 | 同上，缺失不能将其他能力指标改名填入 |
| 7-8 | 专业名称＋历届教学满意度；生成版只列当届 | 按实际上传届次生成列，保留本校平均与专业行；其他评价题不能填入教学满意度 |
| 7-9 | 专业名称；两类对口人群各重要度、满足度；生成版却放课程优劣排名 | 恢复与5-9相同的四项分组结构，使用已关联且符合范围的课程记录；课程排名仅留内部分析 |
| 7-10 | 专业名称、指导总体、高频交流、三项指导满足度 | 恢复六列与两层表头，分项分母分别保留；未知总体公式不取分项均值补值 |
| 7-11 | 专业名称＋四项校内、四项校外评价 | 使用人工版九列、两层表头、列宽与原标签，数字居中，跨页重复完整表头 |
| 7-12 | 专业名称、主要就业省份、历届；每专业通常三省份 | 按实际上传届次生成列；专业纵向合并只留一次名称，省份与各届值逐行对应，加入独立统计的本校平均 |
| 7-13 | 专业名称、就业的主要行业；生成版为宽泛行业类和比例列表 | 填具体行业名称，不另加比例列；两届原始记录均可核验且来源唯一时重新合并计数，否则标实际当届 |
| 7-14 | 专业名称、从事的主要职业 | 同上，使用职业名称，不能用职业类替代；缺少另一届不宣称两届合并 |

人工版的表头名称、分组、单位和单元格格式存入 `agent-service/config/table-templates.json`，其中没有人工版的校本数值、专业名单或历年结果。届次列不再由参考报告的四届格式决定，而是从本次上传资料识别并按年份升序生成。

统计数据与正文表分开保存。原始有效分母、分类、全部选项、匿名关联情况和来源链留在内部计算证据中；整理后的Word表按人工版结构展示。专业行依据上传资料中明确的一流专业标记，同名专业按学院与专业联合匹配，确需区分时在专业名称中标注学院。资料范围不同，实际专业行数或职业分类行数可以与人工版不同，不能复制人工版名单或数值填满。

Word复查另发现两个重复问题：有些专业每个行业或职业都只有1条记录，原来将所有并列项拼成很长的“主要去向”，现保留完整分布但不列该分散结果；表1-10有并列主要职业时按人工版分行并合并学院、专业。模型额外生成的地区比例摘录及一流专业综合指标表，如果原固定统计表已经覆盖，不再重复插入；有新增内容的课程或行动矩阵保留。

用本次任务保存的实际资料离线重新统计后，表5-9、7-9的本校平均四项恢复为80.71、90.69、74.91、89.88，与人工版一致。没有调用大模型或产生API费用；用户原报告和已完成任务文件未改动。Word排版另用新目录中的测试副本检查。

少量学院指标与人工版相差0.01个百分点，不能通过复制人工数值消除。例如理学院教材实用性，原始正向35份、有效39份，直接计算为89.74%；两个正向选项先各自保留两位小数再相加会得到人工版的89.75%。程序统一从原始人数计算后保留两位小数。人工版的部分空缺项，在当前资料可核验计算时填写实际结果，不照抄参考报告的缺失符号。

缺失值不等于零。未上传的届次不创建空列；已识别届次在某张表的指标缺失时，对应单元格保留“—”。只有两届合并指标时不拆成两年。能力达成率算法和教师指导总体指标若未在资料中明示，保持表格结构和缺失位置；不反推人工版公式。

修改入口：`template_tables.py` 控制逐表结构和数据整理；`report_statistics.py`、`linked_statistics.py`、`regional_statistics.py`、`table_history.py` 控制源数据统计与历史对齐；`exporter.py` 控制列宽、合并格、重复表头和Word排版。三个业务skill同步约束表格，模型不再自行重造固定表格的结构。
